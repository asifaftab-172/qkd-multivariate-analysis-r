# QKD Multivariate Analysis in R

Multivariate statistical analysis of experimental **Quantum Key Distribution (QKD)** coexistence measurements for LSU M5 Assignment 5.1.

## Study question

How do optical attenuation and measured QKD performance jointly change under increasing classical-signal injection, and how well can those measurements distinguish the experimental coexistence conditions?

The project uses the **0-km coexistence subset** from five experimental conditions: baseline (no injected signal), 3 dBm, 7 dBm, 9 dBm, and 12 dBm. This holds added-fibre length fixed while examining measured associations with attenuation and injected-signal condition. Unequal attenuation sampling across conditions remains a limitation; these comparisons do not establish a causal power effect.

## Dataset

Horgan, J., Quigley, N., Hajar, B., Briantcev, D., Kaszubowska-Anandarajah, A., & Kilper, D. (2026). *QKD Network Characterisation and Coexistence Datasets with Standardised Performance Metrics and Experimental Methods* (v2). Zenodo. https://doi.org/10.5281/zenodo.21792844

Key quantitative variables:
- `VOA_dB`: optical attenuation (dB)
- `QBER`: quantum bit error rate
- `SecureKeyRate_bps`: secure key rate (bits/s)
- `LogSKR`: `log10(SecureKeyRate_bps + 1)` derived for multivariate analysis

Categorical variable:
- `NoiseCondition`: Baseline, 3 dBm, 7 dBm, 9 dBm, 12 dBm

## Analyses

1. **Preprocessing and EDA**: validity/missing-value checks, descriptive statistics, log transform, standardization, pair plots, correlations, and attenuation-performance trends.
2. **PCA**: variance explained by every component, explicit component-retention decisions, standardized loadings, scree plot, and biplot.
3. **Clustering**: k-means and Ward hierarchical clustering, supported by elbow/silhouette comparisons, a dendrogram, PCA projections, and cluster profiles.
4. **LDA**: five-class linear discriminant analysis with `MASS::lda()`, a stratified 70/30 train/test split, training-only scaling, discriminant coefficients, discriminant scores, and a labeled confusion matrix with counts and row percentages. Overall and class-specific performance show which conditions are hardest to separate.
5. **Multivariate regression**: jointly model QBER and LogSKR with centered attenuation, condition, and their interaction. Interpret Pillai multivariate tests, outcome-specific coefficients and R-squared, fitted relationships, and residual diagnostics.

## Reproduce locally

Run from the repository root:

```bash
Rscript "analysis/M5Assign 5.1 Data__Ronggon_Asif.R"
cd report
pdflatex report.tex
pdflatex report.tex
```

The five original source CSVs are included in `data/raw/` (2,110 observations). The R script can also use the submitted combined CSV; the standalone invocation is described below. When neither local input mode is available, the script downloads missing source files directly from Zenodo. See [data/README.md](data/README.md) for source URLs, row counts, license, and checksums.

To rerun the submitted analysis independently, place the submitted `.R` and `.csv` files together, open a terminal in that folder, and run:

```bash
Rscript "M5Assign 5.1 Data__Ronggon_Asif.R"
```

The standalone script uses `M5Assign 5.1 Data__Ronggon_Asif.csv` in its working directory. When run from the repository root, it uses the original raw CSVs. It recreates `data/processed/`, `figures/`, and `results/`. The repository's LaTeX source is needed only to rebuild the PDF report, not to rerun the R analysis. CI also runs the submitted script and CSV in an isolated folder and compares regenerated PCA and LDA outputs with the main build.

Use R 4.1 or newer with the recommended R packages `MASS` (LDA) and `cluster` (silhouette analysis), plus a LaTeX distribution with the packages listed in `report/report.tex`. If the R packages are absent, install them once with `install.packages(c("MASS", "cluster"))`. The script saves `results/sessionInfo.txt` with the R and package versions and uses a fixed seed for reproducible sampling and clustering. Statistical outputs and vector PDF figures are regenerated from the data rather than copied into the report by hand.

The [GitHub Actions workflow](.github/workflows/build-analysis.yml) installs any missing analysis packages, runs R, compiles LaTeX, and assembles all three submission files. It uploads the `qkd-analysis-and-submission` artifact **before** committing generated outputs, so that the downloadable files remain available if repository settings block the final commit. The workflow does not submit anything to Moodle.

The figures include EDA scatter plots and correlations; a PCA scree plot and biplot; cluster-selection, dendrogram, PCA, and profile figures; LDA score separation and a confusion matrix; and regression fits and diagnostics. Each is saved as a vector PDF under `figures/` so that labels remain sharp in the report.

## Interpretation and scope

The report connects optical-network engineering with statistical learning, reliability, and decisions about secure communication. PCA summarizes correlated behavior; clustering describes performance regimes; LDA evaluates separation of known injection conditions; regression quantifies their relationships with two performance outcomes.

LDA accuracy uses a random, stratified split of observations from the same experimental campaign. It measures within-campaign classification and does not establish performance on independent experimental runs. Repeated attenuation-sweep measurements also limit independence assumptions in regression; its inferential results need that qualification. The study does not establish cryptographic security or a universal deployment threshold. Review the report's diagnostics and limitations alongside its figures and accuracy.
