# QKD Multivariate Analysis in R

Multivariate statistical analysis of experimental **Quantum Key Distribution (QKD)** coexistence measurements for LSU M5 Assignment 5.1.

## Study question

How do optical attenuation and measured QKD performance jointly change under increasing classical-signal injection, and how well can those measurements distinguish the experimental coexistence conditions?

The project uses the **0-km coexistence subset** from five experimental conditions: baseline (no injected signal), 3 dBm, 7 dBm, 9 dBm, and 12 dBm. Restricting the analysis to 0 km intentionally removes added-fibre length as a confounding experimental factor and focuses the multivariate analysis on the classical-signal coexistence effect.

## Dataset

Horgan, J., Quigley, N., Hajar, B., Briantcev, D., Kaszubowska-Anandarajah, A., & Kilper, D. (2026). *QKD Network Characterisation and Coexistence Datasets with Standardised Performance Metrics and Experimental Methods* (v2). Zenodo. https://doi.org/10.5281/zenodo.21792844

Key quantitative variables:
- `VOA_dB`: optical attenuation (dB)
- `QBER`: quantum bit error rate
- `SecureKeyRate_bps`: secure key rate (bits/s)
- `LogSKR`: `log10(SecureKeyRate_bps + 1)` derived for multivariate analysis

Categorical variable:
- `NoiseCondition`: Baseline, 3 dBm, 7 dBm, 9 dBm, 12 dBm

## Analyses

1. **Preprocessing and EDA**: validity/missing-value checks, descriptive statistics, log transform, standardization, pair plots, correlations, and attenuation-performance trends.
2. **PCA**: explained variance, scree plot, loadings, and biplot.
3. **Clustering**: K-means with elbow analysis and Ward hierarchical clustering with dendrograms.
4. **LDA**: five-class linear discriminant analysis using a stratified 70/30 train/test split, discriminant coefficients, LD score plot, confusion matrix, and held-out accuracy.

## Reproduce locally

Run from the repository root:

```bash
Rscript "analysis/M5Assign 5.1 Data__Ronggon_Asif.R"
cd report
pdflatex report.tex
pdflatex report.tex
```

The five original source CSVs are included in `data/raw/` (2,110 observations). The R script downloads a file directly from Zenodo only if it is missing. See [data/README.md](data/README.md) for source URLs, row counts, license, and checksums.

Use R 4.1 or newer with the recommended `MASS` package and a LaTeX distribution with the packages listed in `report/report.tex`. The GitHub Actions workflow installs R and runs the analysis and LaTeX build. Its `qkd-analysis-and-submission` artifact provides the generated files even if committing those outputs is blocked by repository settings.

## Assignment deliverables

After the automated build completes, the `submission/` directory contains:

- `M5Assign 5.1 Data__Ronggon_Asif.R`
- `M5Assign 5.1 Report__Ronggon_Asif.pdf`

The assignment rubric was not included in the supplied project archive. Alignment with its exact criteria and submission requirements still needs to be checked against the original rubric.

LDA accuracy uses a random, stratified split of observations from the same experimental campaign. It measures within-campaign classification and does not establish performance on independent experimental runs.
