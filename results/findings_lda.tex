The fixed stratified split uses 1475 training and 635 test rows. LDA correctly classifies 249 of 635 test observations, giving accuracy 39.2\%. Always predicting the training-majority class (12 dBm) gives 26.8\% on the same test rows, so the accuracy difference is 12.4 percentage points. Macro recall is 32.2\%, which weights the five conditions equally.

Class recall ranges from 0.0\% to 83.5\%; the lowest recall includes 3 dBm (0 correctly classified out of 120). Each heatmap cell shows a count and its percentage of the actual class, and the gold diagonal marks correct predictions. Off-diagonal mass therefore makes the model's errors visible even when class sizes differ. No test observations were predicted as 3 dBm or 7 dBm; precision is therefore undefined for those classes.

These estimates concern held-out rows from the same campaign. Repeated measurements at shared settings can occur in both partitions; this is not validation on independent runs or unseen operating conditions. LDA's common within-class covariance and approximately Gaussian predictor assumptions are also approximations for bounded QBER and zero-heavy SKR.
